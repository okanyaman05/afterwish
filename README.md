# Afterwish, Inc. — Corporate Website

Official corporate and product directory website for **Afterwish, Inc.**, the parent technology company behind:

- **[Nonda AI](https://nonda.ai)** — Multi-model AI creative studio for chat, image, video, voice, music, and collaborative design.
- **[Listuply](https://listuply.com)** — Local classifieds and online marketplace across the United States.

## Tech Stack

- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.
